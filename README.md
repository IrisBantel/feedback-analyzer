# Feedback Analyzer

## Summary

Feedback Analyzer is a simple AI tool that analyzes written feedback from surveys and groups similar comments into common topics. It helps users quickly understand what people liked, disliked, or mentioned most often.

Building AI course project

## Background

Surveys often contain open text fields where people can give feedback in their own words. When many people participate, reading and sorting all responses manually can take a lot of time.

The Feedback Analyzer would help by automatically identifying similar comments and grouping them into common topics.

For example, after an event, participants might write comments about:

* the speakers
* the location
* the organization
* the content
* networking

Instead of sorting every response manually, AI could help identify these recurring themes.

## How is it used?

The user provides a collection of written feedback, for example responses from a survey.

The AI analyzes the texts, looks for similarities, and groups related responses together. The user can then see which topics occur frequently and read the comments belonging to each topic.

The results are intended to support the user. A human should still review the feedback and interpret the results.

## Data sources and AI methods

The data consists of written feedback collected through surveys or feedback forms.

Natural language processing (NLP) can be used to analyze the text. Similarity methods and clustering could then be used to identify responses that discuss similar topics.

## Challenges

The meaning of written feedback is not always clear. People may use irony, different expressions, or discuss several topics in one comment.

The AI may therefore group some comments incorrectly. The results should not replace human judgment.

Privacy should also be considered if the feedback contains personal information.

## What next?

A future version could also identify whether feedback is positive, neutral, or negative.

It could also summarize the most frequently mentioned topics so that users can get a quick overview of a large number of responses.
